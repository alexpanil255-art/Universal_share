# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] — 2026-02

### Added
- Initial public release of Everything Share.
- No-login onboarding with device names and persistent 6-digit codes.
- File upload / download REST API with cloud relay storage.
- Real-time WebSocket incoming notifications.
- Expo Router frontend running on web, iOS, and Android from a single codebase.
- Files inbox with search, kind filters, favorites, sent/received.
- Built-in previews for images, video, audio, PDFs, text, code.
- Smart Board / Presentation mode with pen, highlighter, laser pointer, eraser, and timer.
- Light / Dark / System theming with emerald brand palette.
- MIT license, contribution guide, and CI workflow.
